# 개인 이벤트 원본과 온라인 적용

원본: `03_월드&개인이벤트_70x120mm_3(지웅 수정).pdf`.
48페이지 중 1–16은 월드 이벤트, 17–48은 개인 이벤트 32장이다.
개인 이벤트는 고정 21장, 연봉 구간형 6장, 팀 전원 2장, 선택형 2장, 버킷 교체 1장이다.
대학생 표기 4장은 메타데이터를 유지하고 현재 목록에 포함한다.

## 사용자가 확정한 온라인 규칙

- '참가자 전원'은 같은 팀 전원. 다른 팀에는 적용하지 않는다.
- 월급 구간의 효과값은 유지하며 연봉 1–4 / 5–8 / 9–13단계에 대응한다.
- 부족한 현금과 시간은 음수 처리하지 않고 미납으로 기록한다. 다음 턴 임금·시간 수령 후 차감하고, 그래도 부족하면 다음 턴으로 이월한다.
- 원본 이미지의 월급 표기는 그대로 남아 있으므로 이미지 아래에 온라인 연봉 단계와 실제 적용 효과를 별도 표시한다.

## 데이터

- `personal-event-catalog.js`: 전체 카드와 원본 텍스트·페이지·이미지·효과.
- `integrated/{pid}/eventDraws/{turn}`: 뽑은 카드, 선택, 교체 후보, 적용 상태. 새로고침으로 다시 뽑지 않는다.
- `drawnEventIds`: 참가자별 중복 지급 방지.
- `eventHistory/{sourcePlayer_turn}`: 팀 효과를 포함한 실제 수령·차감 기록. KEEP 표시 보존.
- `eventDebts`: 다음 턴 차감할 현금·시간. `eventDebtPayments`에 수령 시 차감액 기록.
- 버킷 교체는 이벤트 효과로 독립 처리한다. 일반 턴의 버리기 횟수는 소비하지 않으며 최대 5번 뽑는다.

원본 32장의 앞면을 시각 대조했다. PDF 레이어를 다른 PDF에 옮기면 뒷면이 위에 표시되므로 각 원본 페이지를 직접 렌더링한다.
테스트: `node tests/personal-events.test.cjs`.
