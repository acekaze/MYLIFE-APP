# 엑셀 기능 → 앱 기능 대응표

## 시트 → 화면 대응

| 엑셀 시트 | 앱 화면 | 설명 |
|-----------|---------|------|
| 투자상품종류 (Sheet1) | 상품 설정 화면 | 상품 목록, 수익률, 손실률, 주사위 판정 관리 |
| 플레잉시트 (Sheet2) | 투자 입력 + 전체 투자내역 | 투자 기록 입력·조회·수정·삭제 |
| 투자자검색 (Sheet3) | 참가자 검색 화면 | 참가자별 투자내역 필터 + 요약 통계 |

## VBA 매크로 → 앱 기능 대응

| VBA 기능 | 앱 기능 | 처리 방식 |
|----------|---------|-----------|
| `투자자검색` 매크로 | 참가자 검색 화면 | 이름 선택/검색 시 해당 참가자 기록만 필터링 |
| AutoFilter (Field:=2, Criteria1) | 참가자 필터 | 참가자 ID 기준 JavaScript filter |
| B:K열 복사 → 투자자검색 시트 붙여넣기 | 참가자 투자내역 테이블 렌더링 | 실시간 렌더링, 복사 불필요 |
| 필터 해제 | 자동 처리 | SPA 구조로 원본 데이터 유지 |

## 엑셀 열(B~K 추정) → 앱 필드 대응

| 엑셀 열 | 엑셀 항목명 (추정) | 앱 필드명 | 비고 |
|---------|-------------------|-----------|------|
| B | 반기구분 | 턴/분기 | 명칭 변경: 반기구분 → 턴/분기 |
| C | 이름 | 참가자 이름 | AutoFilter 기준 필드 |
| D | 투자상품 | 상품명 | 드롭다운 선택 |
| E | 투자금액 | 투자 금액 (만 원) | 양수만 허용 |
| F | 주사위 | 주사위 값 | 1~6 |
| G | 결과 | 투자 결과 | 성공/원금보존/실패 |
| H | 수익금 | 수익금 | 성공 시: 금액 × 수익률 |
| I | 손실액 | 손실액 | 실패 시: 금액 × 손실률 (음수) |
| J | 원금보존 | 원금보존액 | 원금보존 시: 투자금액 그대로 |
| K | (비고 또는 추가 정보) | - | 필요 시 확인 |

## 엑셀 계산식 → 앱 계산 로직

| 엑셀 수식 (추정) | 앱 계산 | 예시 |
|-----------------|---------|------|
| `=IF(결과="성공", 금액*수익률, 0)` | 성공 시 수익금 = 투자금액 × 상품수익률 | 1000 × 16% = 160 |
| `=IF(결과="실패", 금액*손실률, 0)` | 실패 시 손실액 = 투자금액 × 상품손실률 | 1000 × (-20%) = -200 |
| `=IF(결과="원금보존", 금액, 0)` | 원금보존 시 원금보존액 = 투자금액 | 1000 → 1000 |

**중요:** 성공 결과는 수익금만 계산 (원금 미포함)

## 데이터 유효성 → 앱 검증

| 엑셀 유효성 | 앱 검증 |
|------------|---------|
| 상품 드롭다운 (투자상품종류 시트 참조) | 상품 select 목록 (사용여부=true만) |
| 주사위 값 제한 | 1~6 정수만 허용 |
| 결과 드롭다운 (o/x/원금보존 추정) | 성공/실패/원금보존 선택 |
| 금액 숫자 제한 | 0보다 큰 숫자만 |

## 결과값 표기 대응

| 엑셀 표기 (추정) | 앱 표기 | 비고 |
|-----------------|---------|------|
| o 또는 O | 성공 | 대소문자 통합 처리 |
| x 또는 X | 실패 | 대소문자 통합 처리 |
| 원금보존 | 원금보존 | 그대로 유지 |
