# 월드 이벤트 공개와 적용 결과

- 원본: `MY_NEXT_월드이벤트_전체화면_260903.pptx`의 16개 이벤트. 그림은 PPT 내 원본 이미지, 공지 문구는 PPT 내용을 사용한다.
- 신규 통합 세션의 관리자 월드 이벤트 탭에서 카드를 고르거나 무작위 선택 후 전체 공개한다. 투자가 없어도 공지는 가능하다.
- `worldBroadcasts/{id}` revision 1: 공개 공지. revision 2: 관리자 커스텀 투자 효과의 실제 결과. 대상은 공개 시점의 세션 참가자 전원이다.
- `integrated/{playerId}/worldNoticeSeen/{id}`에 확인한 revision을 저장한다. 공지를 닫아도 결과 적용 시 다시 표시하고, 확인하지 않은 결과는 재접속 시 표시한다.
- `effectsByPlayer`는 기존 커스텀 투자 정산·강제손실·영향 없음 처리와 같은 업데이트에 기록한다. 팝업 확인 버튼은 자산을 다시 변경하지 않는다.
- 이 변경은 PPT의 급여·시간·청약 효과를 자동 실행하지 않는다. 해당 문구는 공지하고 효과 적용은 진행자의 운영에 따른다. '자산 변화 없이 안내 완료'는 실제 자산을 변경했다고 표시하지 않는다.
- 은행 파산은 채권형펀드의 현행 실패율 0%를 유지하는 것으로 사용자 확인: 원금 전액 회수·투자 종료.
- `node tests/world-broadcast.test.cjs`로 대상자·확인 상태·적용 결과를 검증한다.
