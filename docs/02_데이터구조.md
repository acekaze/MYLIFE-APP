# 데이터 구조 설계

## 저장 방식

- localStorage 기반 (로컬 우선, 서버 불필요)
- JSON 직렬화
- 키: `mylife_sessions`, `mylife_products`, `mylife_current_session`

---

## 1. 투자상품 (products)

```typescript
interface Product {
  id: string;                  // UUID
  name: string;                // 상품명
  profitRate: number;          // 만기 수익률 (예: 0.16 = 16%)
  lossRate: number;            // 손실률 (예: -0.20 = -20%)
  earlyTermRate: number;       // 중도해약 연이율 (예: 0.08 = 8%)
  profitDice: number[];        // 수익 주사위 (예: [1,2,3,6])
  preserveDice: number[];      // 원금보존 주사위 (예: [4])
  lossDice: number[];          // 손실 주사위 (예: [5])
  isActive: boolean;           // 사용 여부
  sortOrder: number;           // 정렬 순서
}
```

## 2. 워크숍 세션 (sessions)

```typescript
interface Session {
  id: string;                  // UUID
  name: string;                // 세션명
  date: string;                // 진행일 (YYYY-MM-DD)
  participants: Participant[]; // 참가자 목록
  records: InvestmentRecord[]; // 투자 기록
  createdAt: string;           // 생성일 (ISO)
  updatedAt: string;           // 수정일 (ISO)
}
```

## 3. 참가자 (participants)

```typescript
interface Participant {
  id: string;                  // UUID
  name: string;                // 이름
  sortOrder: number;           // 정렬 순서
}
```

## 4. 투자기록 (records)

```typescript
interface InvestmentRecord {
  id: string;                  // UUID
  participantId: string;       // 참가자 ID
  turn: string;                // 턴/분기 (예: "Q1", "Q2")
  productId: string;           // 상품 ID
  productNameSnapshot: string; // 저장 당시 상품명
  amount: number;              // 투자 금액 (만 원)
  profitRateSnapshot: number;  // 저장 당시 수익률
  lossRateSnapshot: number;    // 저장 당시 손실률
  diceValue: number | null;    // 주사위 값 (1~6, 정기적금 등은 null 가능)
  result: 'success' | 'preserve' | 'fail'; // 투자 결과
  profitAmount: number;        // 수익금 (성공 시)
  lossAmount: number;          // 손실액 (실패 시, 음수)
  preserveAmount: number;      // 원금보존액
  createdAt: string;           // 생성일 (ISO)
  updatedAt: string;           // 수정일 (ISO)
}
```

## 6. 계산 규칙 요약

| 결과 | 계산식 | 저장값 |
|------|--------|--------|
| 성공 | 투자금액 × 수익률 | profitAmount에 저장, 나머지 0 |
| 실패 | 투자금액 × 손실률 | lossAmount에 저장 (음수), 나머지 0 |
| 원금보존 | 투자금액 그대로 | preserveAmount에 저장, 나머지 0 |

**한 기록에 성공·실패·원금보존이 동시에 값을 가지면 안 됨.**

## 7. 주사위 판정 로직

```typescript
function judgeResult(product: Product, diceValue: number): 'success' | 'preserve' | 'fail' {
  if (product.profitDice.includes(diceValue)) return 'success';
  if (product.preserveDice.includes(diceValue)) return 'preserve';
  if (product.lossDice.includes(diceValue)) return 'fail';
  // 정기적금/청약저축처럼 모든 주사위가 수익인 경우
  return 'success';
}
```

## 8. 참가자 요약 계산

```typescript
interface ParticipantSummary {
  totalCount: number;        // 전체 투자 횟수
  successCount: number;      // 성공 횟수
  failCount: number;         // 실패 횟수
  preserveCount: number;     // 원금보존 횟수
  totalProfit: number;       // 총 수익금
  totalLoss: number;         // 총 손실액
  totalPreserve: number;     // 총 원금보존액
  netResult: number;         // 순수익 (수익금 + 손실액)
}
```
