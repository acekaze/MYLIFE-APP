# My Life 투자관리 앱 - 운영 설명서

## 1. 설치 및 실행

### 설치할 것 없음

이 앱은 순수 HTML + JavaScript + CSS로 만들어져 있습니다.  
별도 설치, 서버, 인터넷 연결이 필요 없습니다.

### 실행 방법

1. `MYLIFE-APP` 폴더를 원하는 위치에 복사합니다
2. `index.html` 파일을 더블클릭합니다
3. Chrome 또는 Edge 브라우저에서 바로 열립니다

> 폴더 전체를 USB에 넣어서 어디서든 실행할 수 있습니다.

### PWA 설치 (선택)

Chrome에서 주소창 오른쪽의 설치 아이콘(⊕)을 클릭하면  
독립 앱처럼 설치됩니다. 이후 바탕화면에서 바로 실행 가능합니다.

---

## 2. 화면 구성

| 탭 | 단축키 | 용도 |
|----|--------|------|
| 투자 입력 | Alt+1 | 참가자별 투자 기록 입력 |
| 전체 내역 | Alt+2 | 모든 투자 기록 조회·수정·삭제 |
| 참가자 검색 | Alt+3 | 참가자별 투자 요약·상세 |
| 상품 설정 | Alt+4 | 투자상품 수익률·주사위 설정 |
| 세션/백업 | Alt+5 | 워크숍 관리·내보내기·복원 |

---

## 3. 워크숍 시작하기 (처음 사용)

### 3-1. 세션 만들기

1. **세션/백업** 탭으로 이동
2. **+ 새 세션** 클릭
3. 세션 이름 입력 (예: "2024년 3월 워크숍")

### 3-2. 참가자 등록

같은 화면에서:
- **일괄 추가**: `홍길동, 김철수, 이영희` 형태로 쉼표 구분 입력
- 또는 **투자 입력** 탭에서 한 명씩 추가

---

## 4. 투자 입력 방법

### 기본 흐름

1. **참가자 이름 버튼** 클릭 (상단)
2. **턴/분기** 선택 (Q1~Q20, 직접 입력도 가능)
3. **투자상품** 선택 → 수익률/손실률/주사위 정보 자동 표시
4. **투자 금액** 입력 (만 원 단위, 천 자리 자동 구분)
5. **주사위 값** 선택 → 결과 자동 제안
6. **투자 결과** 확인 또는 수정 (성공/원금보존/실패)
7. **저장** 클릭

### 빠른 입력 팁

- 참가자와 턴은 마지막 선택값이 유지됩니다
- 저장 후 상품·금액·주사위만 초기화되어 같은 참가자의 다음 투자를 바로 입력할 수 있습니다
- 5초 이내 동일 내용 중복 저장이 차단됩니다

---

## 5. 계산 규칙

### 성공

```
수익금 = 투자 금액 × 수익률
```

예: 주식형펀드 1,000만 원 → 수익금 160만 원

### 실패

```
손실액 = 투자 금액 × 손실률
```

예: 주식형펀드 1,000만 원 → 손실액 -200만 원

### 원금보존

```
원금보존액 = 투자 금액
```

예: 주식형펀드 1,000만 원 → 원금보존액 1,000만 원

> 성공 시 수익금만 계산합니다. 원금을 포함한 총액이 아닙니다.

## 6. 상품 목록 및 주사위 판정

| 상품 | 수익률 | 손실률 | 수익 주사위 | 보존 주사위 | 손실 주사위 |
|------|--------|--------|-------------|-------------|-------------|
| 정기적금 | 6% | 0% | 1~6 (전부) | - | - |
| 청약저축 | 6% | 0% | 1~6 (전부) | - | - |
| 채권형펀드 | 8% | 0% | 1,2,3,5,6 | 4 | - |
| 주식형펀드 | 16% | -20% | 1,2,3,6 | 4 | 5 |
| 고위험ETF | 40% | -50% | 1,2,3,4 | 5 | 6 |
| 선물/옵션 | 60% | -60% | 1,2,3 | 4 | 5,6 |

상품 설정 탭에서 수치와 주사위를 자유롭게 수정할 수 있습니다.

## 7. 참가자 검색

참가자 이름 버튼을 클릭하면:

- **요약 통계**: 투자 횟수, 성공/실패/원금보존 횟수, 총 수익금, 총 손실액, 순수익
- **상세 내역**: 턴별 투자 기록 전체, 상품별·결과별 필터

---

## 8. 데이터 백업 및 복원

### 백업 (세션/백업 탭)

| 기능 | 설명 |
|------|------|
| CSV 내보내기 | 전체 투자내역을 엑셀에서 열 수 있는 CSV 파일로 저장 |
| 참가자별 요약 CSV | 참가자별 통계를 CSV로 저장 |
| JSON 백업 | 모든 데이터(세션, 참가자, 기록, 상품)를 한 파일로 저장 |

### 복원

1. JSON 백업 파일 선택
2. **JSON 복원** 클릭
3. 확인 후 전체 데이터 덮어쓰기

### 세션 초기화

- 확인을 두 번 거칩니다
- 초기화 직전 자동 백업 파일이 다운로드됩니다
- 실수로 날려도 백업 파일로 복원 가능합니다

---

## 9. 데이터 저장 위치

모든 데이터는 **브라우저의 localStorage**에 저장됩니다.

주의:
- 브라우저 데이터 삭제 시 투자 기록도 사라집니다
- 워크숍 끝나면 반드시 **JSON 백업**을 받아두세요
- 다른 컴퓨터에서 사용하려면 JSON 백업 → 복원으로 이동합니다

## 12. 검수 테스트 실행 방법

브라우저에서 앱을 연 후:

1. `F12` 키로 개발자 도구 열기
2. **Console** 탭 선택
3. `TestVerify.runAll()` 입력 후 Enter
4. 결과 확인 (✅ 통과 / ❌ 실패)

| 항목 | 엑셀 | 앱 |

## 14. 자주 묻는 질문

**Q: 데이터가 갑자기 사라졌어요**  
A: 브라우저 캐시를 지웠거나 시크릿 모드에서 사용한 경우입니다.  
JSON 백업을 정기적으로 받아두세요.

**Q: 다른 노트북에서 이어서 할 수 있나요?**  
A: JSON 백업 파일을 옮긴 뒤 복원하면 됩니다.

**Q: 상품 설정을 바꾸면 과거 기록도 바뀌나요?**  
A: 아닙니다. 저장 당시의 수익률과 손실률이 기록에 고정됩니다.

**Q: XLSX(엑셀) 파일로 내보낼 수 있나요?**  
A: 현재는 CSV로 내보냅니다. CSV 파일은 엑셀에서 바로 열 수 있습니다.
